# README figure: all Fig. 1 methods plus PCD

The README figure includes **every method in manuscript Fig. 1**—MultiHead, MOBO,
ParetoFlow, PGD-MOO, STCH-PSL and OffPSL—plus the **archived PCD run**. It uses the
original **30-variable**, **60,000-observation** ZDT2 benchmark dataset. All seven
methods have **256 valid generated candidates** at **seed 1000**. No training was
rerun to make this figure. Additional baseline source code is not bundled.

## Evidence and plotting choices

- The original figure source is `scripts/plot_zdt2_method_objective_panels.py`
  in the research project. Its OffPSL source uses the historical `sra_psl` method ID.
- The seven methods' generated results are exported losslessly to
  [`assets/fig1_results.json`](../assets/fig1_results.json). This compact record
  contains recorded objective values (`y_raw`), available preferences (`lambdas`),
  source references and file hashes. OffPSL and STCH-PSL also include their saved
  feasible designs (`x_eval`) for the bottom mapping panels. PCD comes from
  `outputs/synthetic_benchmark/zdt2/pcd/1000/candidates.npz`; its task, seed,
  dimensions and 256 valid rows were checked against the adjacent metadata.
- Only the background observations are subsampled: 3,500 rows, uniformly without
  replacement, using NumPy's generator with seed 1000, as in the original plotter.
  Every valid candidate is shown. No candidate is selected based on its performance.
- All eight objective panels (original observations plus seven methods) use the
  same x/y limits, covering all valid candidates and the offline objective range.
- The common viridis scale encodes recorded first preference weights for MOBO,
  STCH-PSL and OffPSL only. Their actual grids and different endpoint clipping are
  preserved. MultiHead, PCD, ParetoFlow and PGD-MOO have no preference rows in these
  artifacts and are shown in fixed method colors; no preferences were inferred.
  The lower two panels retain OffPSL/STCH-PSL saved designs in original units.
- Objective panels preserve the archived evaluations exactly. Direct analytic ZDT2
  reevaluation on the saved `x_eval` differs by at most about `3.18e-4` for OffPSL
  and `1.58e-4` for STCH-PSL. This record does not establish the cause of the small
  discrepancy, and no stored evaluations or paper statistics were changed.
- The archived STCH-PSL run fitted its surrogate on the top 100 offline designs.
  It is the paper's local adaptation, distinct from the compact release's full-data
  quick-start adaptation. The plotted results are not claimed to be generated by
  the quick-start defaults.

## Replot

Install the plotting extra, then obtain the original observations separately from
[Off-MOO-Bench / offline-moo](https://github.com/lamda-bbo/offline-moo#data-downloading).
The benchmark dataset is **not included** in this repository. From the release root:

```bash
python -m pip install -e ".[demo]"
python examples/plot_fig1.py --offline-y ../offline-moo/data/zdt2/zdt2-y-0.npy --results assets/fig1_results.json --out runs/fig1/zdt2
```

Adjust the external data path to its actual location. The expected original
`zdt2-y-0.npy` SHA256 is:

```text
6fdf6802a3806cd27227478faa08b406c56b560c3fb3fe849e1c5573b4002afa
```

The plotter verifies the checksum and refuses a different dataset, so it cannot
silently substitute the near-front synthetic quick-start data. If a newly downloaded
dataset differs, it cannot be labeled as this exact archived figure without checking
its version. No benchmark Python imports or old training checkpoints are needed.

The command writes PNG, editable SVG, and `zdt2_plot.json` with source identity,
counts, axis limits, package versions, and measured plotting time. The recorded
local render took about two seconds after imports; it is **plotting time**, not
training time. The shipped rendering record is
[`assets/zdt2_plot.json`](../assets/zdt2_plot.json).

The separate [synthetic smoke example](EXAMPLE.md) remains available for testing
installation and training without downloading benchmark data. It does not reproduce
this figure or the paper's benchmark experiments.
